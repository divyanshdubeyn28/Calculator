# 🧮 Divyansh Calculator

A modern, ultra-premium 3D glassmorphic calculator web application built with HTML5, CSS3, and Vanilla JavaScript. Designed with an immersive dark-mode neon aesthetic, smooth tactile button animations, and custom developer branding.

---

## ✨ Features

- Ultra-Premium 3D Glassmorphism: Deep multi-layered shadows, glowing neon accents, and metallic gradient buttons.
- Custom Branding: Features a custom DIVYANSH CALCULATOR header with glowing futuristic styling.
- Responsive Layout: Perfectly scaled for mobile, tablet, and desktop screens with smooth spacing and typography.
- Full Keyboard Support: Type numbers, use operators (+, -, *, /), hit Enter for equals, Backspace to delete, or Escape to clear.
- Robust Calculation Engine: Handles basic arithmetic, percentages, floating-point precision noise cleaning, and division-by-zero error safety.

---

## 🛠️ Tech Stack

- HTML5 (Semantic markup & layout structure)
- CSS3 (Custom properties, Flexbox, Grid, Glassmorphic effects, and Google Fonts like Orbitron & Outfit)
- JavaScript (ES6+) (Modular event-driven calculation logic)

---

## 🚀 Getting Started

To run this project locally on your machine, follow these simple steps:

1. Clone the repository:
   git clone https://github.com/divyanshdubeyn28/Calculator.git

2. Navigate to the project folder:
   cd Calculator

3. Open the project:
   Simply open index.html in your favorite web browser (Chrome, Edge, Firefox, etc.).

---

## 💡 Usage Preview

- Click on the keypad or use your keyboard to perform calculations.
- Press AC to reset everything or DEL to remove the last entered digit.
